# Brilha Talento — protótipo web

Protótipo front-end responsivo inspirado na referência enviada.

## Estrutura
- index.html — estrutura das telas
- styles.css — visual, responsividade e componentes
- app.js — navegação e interações
- assets/ — imagens SVG genéricas, fáceis de substituir

## Como executar
Abra `index.html` no navegador.

## Funcionalidades já incluídas
- Tela inicial/login/cadastro
- Home com banner, categorias e talentos em destaque
- Busca e filtros
- Explorar talentos
- Favoritos persistidos em localStorage
- Perfil
- Envio de talento com seleção de vídeo
- Tela de visualização de talento
- Curtir/seguir/comentar (interface)
- Notificações
- Configurações
- Navegação inferior no celular e menu lateral no desktop
